# Part 3 – Component Investigation
Photograph and investigate the following components.
Images should be stored in:
```
images/components/
```

| Component | Function | Key Specification |
|----------|----------|------------------|
| CPU |processes instructions, performs calculation, and manages data flow between components. | |
| RAM |provides volatile, high speed temporary storage for data currently being used by active programs. | |
| Storage |holds non-volatile, permanent data including the operating system, applications, and user files. | |
| Motherboard | acts as the main printed circuit board that physically connects and enables communication between all hardware| |
| Power Supply |converts alternating current(AC) from a wall outlet into regulated direct current(DC) power for internal parts. | |
| Cooling |Dissipates thermal energy produced by high heat components to maintain safe operating temperatures. | |
